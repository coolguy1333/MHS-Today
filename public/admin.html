    People

    Owners come from the ADMIN_EMAILS setting and can't be changed here. Any admin can make someone else an admin, verify people so they can post events, and edit, reset or lock a profile.

    PersonGoogle emailLast sign-inCan post eventsActions

    Announcements

    A banner at the top of every page from the start date to the end date (for example a snow day or spirit week). People can close it on their device.

    Countdowns

    Shown on the Today page until the date passes (finals, prom, winter break…).

    Blocked words

    Added to the built-in filter for names, bios, events, study sessions, groups, posts and polls. One word per line; whole words only.

    Important links

    The Links page shows these, after the Tools section, grouped by category in this order. Web addresses must start with https:// (or http://).

    Tools

    The Tools section at the top of the Links page, in this order. A tool with no web address shows "Coming soon". Students' suggestions appear under Needs attention.

    Backup and restore

    Everything lives in one file on the server (/data/db.json). WebManager backs up /data before each restart or update, and the site keeps a daily copy in /data/backups. For a copy you control, download one here.
