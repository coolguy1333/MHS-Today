How students see your plans

A student sees a plan when their My classes has the class in the same color block, with the same class name as yours and your last name as the teacher. Each class shows how many students that is. If students typed the name differently, you can switch to their name with one click.

Prep or duty periods (a class named "Prep", "Planning" or "Duty") don't get a plan box.
